# 飞牛音乐 · 电视＆车机版

面向 Android TV / 小米电视 / 通用电视盒子的飞牛音乐（trim.music）播放器。
遥控器操作，**直连任意一台飞牛（fnOS）NAS 上的官方音乐接口**，不依赖任何第三方中转服务。

**当前版本：v2.2.8（2026-11-26）

## 架构

```
电视/盒子 (APK)  ──HTTP(S) + Cookie music-token + authx──▶  你的飞牛 NAS
                                                          :<你自己的端口>/music/api/v1
                                                          曲库：/vol*/.../Music
        MediaPlayer 播放 /track/stream（Range 流式）
```

- 数据全部来自官方接口：最近播放、歌手、专辑、歌单、所有歌曲、搜索、封面、歌词。
- 端口**不写死**：飞牛 WebUI 端口由用户自己设定，App 里按 `IP:端口` / DDNS 域名 / FN ID 三种方式填。
  只填 IP 或域名时默认补 `<端口>`（飞牛默认端口）；填 FN ID 自动走 `https://<id>.5ddd.com`。
- 登录走官方 `POST /music/api/v1/user/password-login`，拿到 `userToken` 即 `music-token` Cookie。

## 功能

首页（最近播放 / 歌手 / 专辑 / 歌单）、所有歌曲（分页）、歌手/专辑/歌单详情、搜索、
播放页（封面、歌名/歌手/专辑、进度条、歌词、循环三态、随机、±10 秒、返回）。

遥控器：

- 首页/列表：方向键移焦点，OK 确认
- 播放页：可聚焦控制条 —— 上一首 / 暂停 / 下一首 / 循环 / 随机 / ±10 秒 / 歌词 / 返回
- 播放页 ◀ ▶ 单击 = 移焦点，长按 = 快退/快进 10 秒；MENU = 歌词开关
- MEDIA 多媒体键（暂停/上一首/下一首）可用；BACK 返回

## 安装

U 盘拷 APK 到电视安装；或 `adb connect 电视IP:5555 && adb install -r 飞牛音乐TV-v1.10.0.apk`。
详见 `文档/使用说明.md`。

## 构建（本机已验证）

```powershell
# 依赖：JDK 17 / Android SDK 34 / gradle 8.9
$env:JAVA_HOME = "C:\Program Files\Eclipse Adoptium\jdk-17.0.21.9-hotspot"
$env:ANDROID_HOME = "D:\Android\Sdk"
cd 源代码\android
gradle assembleRelease    # 产物 app/build/outputs/apk/release/app-release.apk
```

签名：`源代码/android/keystore/miyintv.jks`（CN=MiyinTV），版本间保持一致，可直接覆盖安装。
